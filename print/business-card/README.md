# River Musa Show business card (Inkscape)

`river-musa-business-card.svg` is an Inkscape 1.2+ file with two pages, **Front** and **Back**.
Card size 85 × 55 mm; each page is 91 × 61 mm (3 mm bleed on every side).

1. Install the font first: double-click `BebasNeue-Regular.ttf` → Install (free, SIL Open Font License, see `OFL-bebas-neue.txt`).
2. Open the SVG in Inkscape. Double-click any text to edit it.
3. Replace the placeholders on the back: phone, email, website, YouTube handle.
4. QR code: delete the dashed "QR" box, then **Extensions → Render → Barcode → QR Code**, enter your website, and place it where the box was (about 20 × 20 mm).
5. To check the cut line (pink) and safe area (blue), switch on the "Print guides" layer in the Layers panel. Switch it off again before exporting.
6. For the printer: **File → Save a Copy → PDF**, tick "Convert text to paths", "Use document's page size". Tell the printer: 85 × 55 mm, 3 mm bleed included.
