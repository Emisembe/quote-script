### CSS Variables Available

```css
--brand:       #5DADE2          /* Primary brand color */
--brand-dark:  #2e86c1          /* Darker shade */
--dark:        #0f172a          /* Dark backgrounds */
--nav-bg:      rgba(...)        /* Navigation background */
--text:        #2e2e2e          /* Main text */
--text-muted:  #606060          /* Secondary text */
--light-bg:    #f8f9fb          /* Light backgrounds */
--white:       #ffffff          /* White */
--shadow:      0 4px 24px ...   /* Box shadows */
--radius:      6px              /* Border radius */
--row-max:     1170px           /* Max container width */
--nav-h:       64px             /* Navigation height */
--transition:  all 0.3s ease    /* Animations */
```

### Customization Examples

**Change brand color:**
```css
--brand: #27ae60;  /* Green instead of blue */
```

**Change hero image:**
```css
background: url(new-image-url) no-repeat center center;
```

**Make 2-column grid instead of 3:**
```css
.post-grid { width: 50%; }
```
