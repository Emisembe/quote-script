Interrelationship Diagram find the root cause

Give each idea an ID. Under Causes, list the IDs this idea leads to (e.g. 4, 7). Most arrows out = key driver (root cause). Most arrows in = key outcome.

Tree Diagram break a goal into steps

The top item has no parent. Every other item names its parent's ID. Keep breaking down until each end is a task someone can do.

PDPC plan for what could go wrong

For each task ask: what could go wrong? Write risks and a countermeasure for each, in the same order, separated by ;. A risk without a countermeasure is open.

Activity Network Diagram schedule and critical path

List every task, how long it takes, and which tasks must finish first (e.g. A, C). The critical path is the longest chain — those tasks cannot slip without delaying the project.
