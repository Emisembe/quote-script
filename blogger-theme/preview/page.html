ISO 9001 Readiness: A Practical Checklist for Kenyan SMEs

12 March 2026 Quality

Most small and medium businesses don’t fail certification because their products are poor. They fail because nobody wrote down how the work is actually done. This checklist walks through what an auditor will ask for, in the order they usually ask for it.

1. Define the scope

Start with the sites, products and processes the certificate will cover. Keep it narrow for the first audit; you can extend the scope later.

  • List every site and what happens there
  • Name an owner for each core process
  • Note any outsourced work
An auditor wants evidence, not intentions. If it isn’t recorded, it didn’t happen.

2. Map the processes

A one-page process map per activity beats a 60-page manual. Inputs, outputs, owner, and how you measure it.
