# Quote Script & Blogger Template

This repository contains two main projects:
1. **Quote Script** - JavaScript utility for generating quotes
2. **Blogger Template** - Modern, responsive Blogger template for consultancy websites

---

## 📋 Blogger Template

A professional, SEO-optimized Blogger template designed for consultancy and business websites.

**Version:** 2.0  
**Status:** Ready for use

### Quick Features

- ✨ Modern, responsive design
- 🔍 SEO optimized with structured data
- 📱 Mobile-friendly with hamburger navigation
- 🎨 Easily customizable with CSS variables
- ⚡ Fast and lightweight

### Quick Start

1. Go to Blogger Dashboard → Theme → Edit HTML
2. Replace your current template with `efic-consultancy-blogger-template.xml`
3. See [templates/INSTALLATION.md](templates/INSTALLATION.md) for detailed instructions

### Files

- `templates/efic-consultancy-blogger-template.xml` - Main template
- `templates/INSTALLATION.md` - Setup guide
- `templates/CUSTOMIZATION.md` - Customization guide
- `templates/README.md` - Full documentation
