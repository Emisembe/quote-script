# KPUWU logo concept (for consideration)

A proposal for a new KPUWU logo, kept separate from the website theme. The theme doesn't use or depend on these files: the website shows whatever logo is set in Blogger (Layout → Header).

- `kpuwu-logo-concept.png`: overview sheet with the website header version, white-on-dark, stacked, and small sizes (favicon, WhatsApp).
- `kpuwu-emblem-concept.svg`: the emblem on its own, as a vector file a designer can refine.

## Why a new logo

The current logo puts the union name, email, phone number and social icons inside one small image. In a website header that text is only a few pixels tall and unreadable. The contact details can't change without redrawing the logo. The fine details (laurel, ribbon text) blur at small sizes, so it doesn't work as a browser-tab icon.

## The idea

- Keeps today's two symbols: a graduation cap (universities) and workers standing together.
- Flat shapes in two colours plus white (union red #C8102E, navy #13294B), so it prints cheaply and stays sharp from a banner down to 16px.
- "KPUWU" set in Oswald Bold, with the full name underneath. Contact details stay out of the logo.

This is a concept to show the direction, not final artwork. A designer should finalise it, and the union should approve it, before it's used.
