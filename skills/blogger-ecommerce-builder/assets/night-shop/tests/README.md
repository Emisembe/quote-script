# Night Shop tests

Run from the project root (the folder with `preview/`, `src/`, `apps-script/`).

| Script | What it checks | Run |
|---|---|---|
| `browser-full.js` | Every page at iPhone 13, Galaxy S9+, iPad Mini and desktop width (no sideways scroll, no script errors); the whole checkout on a phone: required options, cart quantity, empty-form message, delivery partners and price change, Place order (sheet + bank details), WhatsApp, Telegram (copy), email, PayPal button, digital-only checkout; homepage blocks, FAQ, chat bubble under the cart drawer, newsletter, Kenya request form. The Google Sheet, YouTube and the blog feed are faked. | `python3 -m http.server 8765 --bind 127.0.0.1 &` then `node tests/browser-full.js <screenshot folder>` |
| `browser-ask-ticker-branches.js` | News ticker (moves, pause button, hidden copy, `*figures*`, reduced motion), branches (Call / WhatsApp / Directions links, LocalBusiness data), "Ask" chat assistant (opens inside the screen, suggestions, 7 questions in other words, links in answers, unknown question → WhatsApp with the question + one anonymous log), German answers, empty gadgets hide everything and bring back the WhatsApp button; four screen sizes. | same server, then `node tests/browser-ask-ticker-branches.js <screenshot folder>` |
| `browser-languages.js` | Swahili, Arabic (right to left), Amharic, Tigrinya on phone and desktop: page language and direction, translated chat bubble, ticker, FAQ, section titles and shop buttons, native names in the language menu, chat answers to typed questions in each language, no sideways scrolling; Arabic product page; empty reviews section stays hidden; dark text in the newsletter box; readable language menu. Needs Noto Sans Ethiopic/Arabic installed locally (npm `@expo-google-fonts/noto-sans-ethiopic`, `…-arabic` → `~/.local/share/fonts`). | same server, then `node tests/browser-languages.js <screenshot folder>` |
| `browser-logos.js` | Partner logos: wide/tall/square/padded logos fit equal tiles without stretching, whole tile clickable (outside links in a new tab), broken picture link falls back to the name, `#` notes hidden, text-only partners stay badges; default row look (no boxes, grey) and `style: tiles` + `grey: no`; desktop and phone. | `node tests/browser-logos.js <folder with wide.png tall.png square.png padded.png> <screenshots>` |
| `inbox-orders.js` | Code.gs in Node with fake Google services: header upgrade of an old Orders tab, delivery/weight fees re-checked server side, digital orders, Downloads tab, Status = Paid → download email, menu resend, cached products. | `node tests/inbox-orders.js apps-script/Code.gs <out folder>` |
| `inbox-requests.js` | Code.gs request forms (Requests tab, owner email, consent and contact checks) and newsletter double opt-in (confirm / unsubscribe links, duplicates, invalid tokens), unanswered chat questions (Questions tab, no email, empty refused). | `node tests/inbox-requests.js apps-script/Code.gs` |

A "FAIL" can be the test, not the shop: read the info column before changing code (example: choosing pickup
does not change a total that is already above `free_shipping_over`).
